# Logos de usuario

Sube logos propios PNG/JPG de hasta 8 MB a esta carpeta en tu propio fork. Se recomienda PNG cuadrado y fondo transparente. Copia la URL **Raw** y pégala en RyouHub → Personalización → Logo personalizado. Puedes subir logos de servidores de Discord, emblemas personales y otras identidades que tengas permiso de usar. Ver [guía completa](../../../docs/ASSETS_Y_PERSONALIZACION_V12.md).
