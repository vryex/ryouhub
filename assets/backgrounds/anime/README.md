# Fondos anime originales Ryou V12

Cuatro wallpapers originales, optimizados para descarga ligera en Roblox Android. Creados para RyouHub y guardados en este repo: `ryou_estacion_nocturna.jpg`, `ryou_santuario_violeta.jpg`, `ryou_estacion_lluvia.jpg`, `ryou_jardin_luna.jpg`.

No son copias de pines ni ilustraciones tomadas de Pinterest. Para cambiar alguno en tu fork, conserva su nombre o actualiza `RYOU_BG_PRESETS` en el script.
