# Fondos de usuario

Sube imágenes PNG o JPG de hasta 8 MB a esta carpeta en tu propio fork. Después copia la URL **Raw** y pégala en RyouHub → Personalización → Fondos. Si quieres agregarlas como presets, edita `RYOU_BG_PRESETS` en tu script V12. Ver [guía completa](../../../docs/ASSETS_Y_PERSONALIZACION_V12.md).
