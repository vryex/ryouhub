# Cambios de Ryou UI

## 14.0.0

- Punto de entrada de cliente para Roblox Studio. Conserva la estructura de ventana, pestañas y controles de la API visual de V12.
- Marca geométrica nueva, launcher compacto y navegación lateral con grupos e iconos nativos.
- Introducción escalonada, transiciones cortas y ajustes de movimiento completo, reducido y desactivado.
- Paneles de una columna, mejor separación de controles y dropdown inline con búsqueda, selección múltiple y opciones dinámicas.
- Notificaciones con cuatro estados, cierre automático y apilado limitado.
- Documentación en español, guía inicial en inglés, ejemplos y prueba de humo.
